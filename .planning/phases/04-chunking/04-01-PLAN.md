       def cleanup_chunks(chunks: list[Chunk], original_path: str | Path) -> None:
           """Remove tempdirs owned by the chunker. SKIPS the bypass sentinel
           where a chunk points at the original input file.

           Safe to call multiple times (ignore_errors=True).

           original_str = str(original_path)
           parents: set[Path] = set()
           for ch in chunks:
               if ch.local_path == original_str:
                   continue  # bypass sentinel — do NOT touch user input
               parents.add(Path(ch.local_path).parent)
           for parent in parents:
               shutil.rmtree(parent, ignore_errors=True)

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller → lib/video_chunker.py | video_path string arrives from the meta skill or selector; treated as untrusted path |
| lib/video_chunker.py → subprocess | ffmpeg / ffprobe CLI invocations; argv must be a list, shell=False, no interpolation |
| lib/video_chunker.py → filesystem | mkdtemp creates writable scratch; cleanup removes only dirs the chunker created |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering / Injection | subprocess.run ffmpeg / ffprobe invocations | mitigate | Command is always a `list[str]` with `shell=False`; `video_path` is str-ified but never concatenated into a shell string; ffmpeg's `-i` takes the raw path, defeating shell interpretation |
| T-04-02 | Denial of Service | Unbounded subprocess run | mitigate | Explicit `timeout=1800` (ffmpeg) / `timeout=30` (ffprobe); `subprocess.TimeoutExpired` surfaces as `VideoChunkingError` |
| T-04-03 | Information Disclosure | stderr captured and echoed in VideoChunkingError message | accept | Stderr from ffmpeg/ffprobe on local files contains no secrets; including it materially improves debuggability. No network calls, no credentials in scope |
| T-04-04 | Repudiation / Data Loss | `cleanup_chunks` deleting the user's original input | mitigate | Bypass sentinel: `if ch.local_path == str(original_path): continue` — covered by test_cleanup_chunks_skips_bypass_sentinel; dedicated regression test guards this |
| T-04-05 | DoS (disk) | Tempdir leak on orphaned mid-split failure | mitigate | `except CalledProcessError / VideoChunkingError` branch calls `shutil.rmtree(tmpdir, ignore_errors=True)` before re-raising |
| T-04-06 | Elevation of Privilege | ffmpeg binary PATH hijack | accept | Process-level concern; matches `scene_detect.py` precedent; PATH hardening is an ops task, not a library one |
</threat_model>
