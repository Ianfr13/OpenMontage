    3. **Public validator** (module-level function):
       ```python
       def validate_synthesized_pipeline(manifest: dict) -> list[str]:
           """Semantic validation of a synthesized pipeline manifest.

           Checks:
             - every stage's `skill:` path exists on disk under skills/<path>.md
             - every tool in every stage's `tools_available` appears in the registry

           Returns a list of issue strings. Empty list = pass.
           Does NOT raise — callers decide how to surface issues. Use
           `raise_if_invalid(manifest)` for a raising convenience wrapper.
           """
           from tools.tool_registry import registry  # local import — avoid startup cost
           registry.ensure_discovered()              # idempotent, per Pitfall 6
           known_tools = set(registry.list_all())

           issues: list[str] = []
           for stage in manifest.get("stages", []):
               stage_name = stage.get("name", "<unnamed>")
               skill = stage.get("skill")
               if skill:
                   skill_path = SKILLS_DIR / f"{skill}.md"
                   if not skill_path.exists():
                       issues.append(
                           f"stage {stage_name!r}: skill file not found: {skill_path}"
                       )
               for tool in stage.get("tools_available", []) or []:
                   if tool not in known_tools:
                       issues.append(
                           f"stage {stage_name!r}: tool {tool!r} not in registry "
                           f"(known {len(known_tools)} tools after ensure_discovered)"
                       )
           return issues


       def raise_if_invalid(manifest: dict) -> None:
           """Raises SynthesisValidationError if validate_synthesized_pipeline returns issues."""
           issues = validate_synthesized_pipeline(manifest)
           if issues:
               raise SynthesisValidationError(issues)
       ```

       ```python
       def _unified_diff(base_manifest: dict, synthesized: dict, *, base_name: str) -> str:
           """Return a unified diff of the two manifests dumped as canonical YAML."""
           import difflib
           from io import StringIO
           yaml = YAML(typ="rt")
           yaml.preserve_quotes = True
           yaml.indent(mapping=2, sequence=4, offset=2)
           yaml.width = 120
           yaml.default_flow_style = False

           buf_a, buf_b = StringIO(), StringIO()
           yaml.dump(base_manifest, buf_a)
           yaml.dump(synthesized, buf_b)

           diff_lines = difflib.unified_diff(
               buf_a.getvalue().splitlines(keepends=True),
               buf_b.getvalue().splitlines(keepends=True),
               fromfile=f"base/{base_name}.yaml",
               tofile=f"synthesized/{base_name}.yaml",
               n=3,
           )
           return "".join(diff_lines)
       ```

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| manifest input → validator | Synthesized manifest may be malformed (especially post-LLM-fill in Plan 05-03) |
| validator → filesystem (skills/) | os.path.exists is an info disclosure vector if paths are user-controlled — mitigated by skill-path coming from a closed set (base pipeline's authored skills) |
| validator → tool registry | registry.list_all() depends on ensure_discovered side-effect; must be idempotent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-08 | Information Disclosure | skill path check leaks filesystem layout via issue string | accept | Issue strings contain repo-relative path; this IS the desired information for a human reviewer. Not a secret. |
| T-05-09 | Tampering | Stage `tools_available` carries adversarial name causing registry traversal | mitigate | `tool not in known_tools` is a set-membership check — no string interpolation into imports/execs. Safe. |
| T-05-10 | Denial of Service | Huge stages list + slow `os.path.exists` | accept | Stages list bounded by schema; filesystem stats are fast. No resource amplification. |
| T-05-11 | Elevation of Privilege | Validator passes, but record's `validation_status` tampered externally | mitigate | Record passes through `jsonschema.validate` before return; status field is enum-constrained. Downstream consumers see the validated record only. |
| T-05-12 | Spoofing | `SynthesisValidationError.issues` parsed as trusted format by caller | accept | `.issues` is a `list[str]`; callers treat it as display text only (Plan 05-03 meta skill shows to user). Not machine-parsed. |
| T-05-13 | Tampering | `list_pipelines` recursive glob leak via future refactor | mitigate | Explicit `startswith("_")` filter. Defense-in-depth regardless of glob shape. |
</threat_model>
