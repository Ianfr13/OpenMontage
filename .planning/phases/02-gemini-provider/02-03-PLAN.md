**Section 2 — Auth + model table (named `## Auth` or similar):**
- `GEMINI_API_KEY` is primary. `GOOGLE_API_KEY` is the fallback. Our wrapper enforces this order explicitly (the underlying SDK reverses it — NEVER rely on the SDK default).
- Get a key at https://aistudio.google.com/apikey
- Model table:
  | Model | Role | When |
  |-------|------|------|
  | `gemini-3.1-pro-preview` | Target (highest quality for video) | Default; tool uses this first |
  | `gemini-2.5-pro` | Stable fallback | Auto-selected when preview raises ClientError (model-not-available) |
  | `gemini-2.5-flash` | NOT recommended | Smaller context window; inadequate for 4-dimension analysis |
- Env var override: `GEMINI_VIDEO_MODEL` pins a specific model.

**Section 3 — Files API quirks sidebar (named `## Files API — what to know`):**
- All videos go through `client.files.upload(...)` regardless of size (NOT inline base64 — `google-genai` SDK uses Files API uniformly for video)
- 48-hour auto-delete by Google; the tool still deletes explicitly in `finally:` to keep quota clean
- 2 GB per-file cap (https://ai.google.dev/gemini-api/docs/files)
- Supported video formats: `mp4`, `mov`, `mpeg`, `avi`, `flv`, `webm`, `wmv`, `3gp`
- Upload transitions: `PROCESSING → ACTIVE` (success) or `PROCESSING → FAILED` (error); no built-in polling helper — the tool owns the while-loop with a 300s wall-clock cap by default

**Section 4 — Structured-output pattern (code block, titled `## Structured JSON output`):**
Include a working code snippet showing:
```python
from google import genai

from lib.schema_adapter import to_api_schema

    ...

```
State plainly: "Do not use `response.parsed`. The `response_json_schema` path with explicit `json.loads(response.text)` is the deterministic one."

Four sub-sections, one per canonical dimension. Each sub-section needs at minimum one example of a good vs bad extraction prompt/output pair (RESEARCH Finding 10 says "2+" — ship at least 1 per dimension in v1, target 2 where length budget allows).

For each dimension list:
- The top-level JSON keys the schema expects (read from `schemas/artifacts/video_analysis.schema.json`)
- Good vs bad extraction examples (show a BAD output — e.g., vague `"fast"` — and a GOOD output — e.g., `"cuts_per_minute": 32, "pacing_style": "frantic"` with confidence entry)
- Dimension-specific gotchas (e.g., for `visual_style`: "Gemini will NOT reliably identify typefaces; `typography_style` is a description only, never an assertion of font family")

The 4 dimensions to cover:
1. **`editing_pacing`** — `cuts_per_minute`, `pacing_style`, `shot_length_distribution`, etc. Teach: include the `shot_boundaries` from `scene_detect` when available; if absent, tell Gemini to infer and set `shot_boundary_source: "model"`.
2. **`audio`** — voice characteristics, music energy, SFX density. Gotcha: audio duration-weighting matters (Phase 4 will chunk). In Phase 2 (single-chunk), Gemini infers audio holistically.
3. **`visual_style`** — `dominant_colors_hex`, `dominant_visual_style`, `typography_style`, motion treatment. Do NOT ask Gemini to identify typefaces; description only.
4. **`narrative`** — `hook_type`, `cta`, section structure. Hook comes from the first few seconds; CTA from the last shot.

**Section 6 — Confidence-map pattern (named `## Confidence maps — always emit "low", never omit`):**
```json
"editing_pacing": {
  "cuts_per_minute": 32,
  "pacing_style": "frantic",
  "confidence": {
    "cuts_per_minute": "high",
    "pacing_style": "medium",
    "shot_length_variance": "low"  // ← model was uncertain; present with "low" rather than absent
  }
}
```
Explicit instruction for the agent to include in every prompt it writes: _"For every uncertain or absent field, populate the dimension's `confidence` map with the field-name → `low` entry. NEVER omit a required field and NEVER emit `null`."_

**Section 7 — 5-minute timecode hallucination warning (named `## Timecode hallucination (>5 min videos)`):**
- Gemini hallucinates round-number timecodes (e.g., `30.0s`, `60.0s`, `90.0s`) past the 5-minute mark when it can't actually see scene boundaries
- **Mitigation:** if `video.duration > 300s`, always pass `shot_boundaries` (from `scene_detect` in Phase 4's chunking flow). If you don't, flag the artifact's `confidence` map accordingly.
- Phase 4 chunks videos above 5 minutes into ≤5-minute segments — this warning applies to chunk-level prompting inside that flow.

**Section 8 — Security + isolation (named `## Security`):**
- Never log or include the API key in any prompt, error, or response
- Uploaded videos auto-delete at 48h; the tool deletes sooner in `finally:` to keep quota clean and prevent cross-run isolation issues
- `video_path` is trusted input from the OpenMontage agent — no sandboxing applied
