## Overview

Added two capabilities to OpenMontage: **structured video analysis** across 4 canonical dimensions (editing+pacing, audio, visual style, narrative) via two interchangeable providers (Gemini SDK direct and OpenRouter), and a **pipeline synthesizer** that turns that analysis into a persistent, validated `pipeline_defs/` YAML ready for production use.

Build order was contract-first: schemas and the adapter shipped before any provider; the selector shipped alongside the first provider; chunking layered on top of a working provider; the synthesizer consumed analysis artifacts; meta skills and AGENT_GUIDE closed the loop; tests validated the full stack including backward compat.

## Milestone Summary

### Decimal Phases
None — all work landed in integer-numbered phases.

### Key Decisions
- **Two providers, one selector contract** — identical canonical shape (ANLZ-06) enforced by cross-provider test; selector is the only public entry point
- **Staging-before-approval for synthesis** — SYNTH-10 no-auto-approval structurally enforced via separate `accept_synthesis` / `reject_synthesis` functions + contract-test guard
- **Rule-based base-pipeline matching** — deterministic scoring on `pacing_style` + `talking_head_heavy` + `static_heavy` + stage count; LLM only fills stage details, never invents structure
- **Lazy `_FLAT_SCHEMA` + explicit `api_key=` pass** — both providers avoid import-time errors and SDK-default env-var confusion (post-Phase-2 fix pattern mirrored in Phase 3)
- **Chunking as orchestration, not tool** — `lib/chunked_analyzer.py` wraps selector output with ThreadPoolExecutor + merger; selector stays single-shot and thread-safe
- **SKILL-03 as manual HUMAN-UAT gate** — real-video quality review deferred (not a code gap; by-design human verification)

### Issues Resolved
- Manifest schema `additionalProperties: false` blocked `expected_analysis` annotations — extended additively (non-breaking) in Phase 5
- `list_pipelines` already excluded `_staging/` via non-recursive glob; added defense-in-depth underscore-prefix filter
- SDK env-var priority inversion (google-genai prefers GOOGLE_API_KEY over GEMINI_API_KEY) fixed by explicit `api_key=` pass in Gemini tool
- Integration checker found 3 docs/wiring drift items (selector `[0]` snippet, selector agent_skills missing openrouter, VIDEO_SYNTH_LLM_FILL default mismatch) — all fixed inline pre-close
