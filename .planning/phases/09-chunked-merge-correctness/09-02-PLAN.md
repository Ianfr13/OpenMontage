Fix v2.0 Phase 4 MR-01 (CLEAN-05) + MR-03 (CLEAN-07):

**CLEAN-05 (MR-01):** `lib/chunked_analyzer.py:418,469` extracts `provider_name = getattr(provider_tool, "provider", None) or "unknown"` and passes it to `merge_analyses(pairs, provider=provider_name)`. If the caller hands in a provider tool whose `.provider` is anything outside `{"gemini","openrouter"}` — e.g. `"anthropic"`, `"local"`, or the literal fallback `"unknown"` (triggered when the attribute is missing or None) — the terminal `validate_artifact` inside `merge_analyses` raises a confusing jsonschema `ValidationError`. Tests currently hide this because every `StubProvider` hardcodes `provider = "gemini"` (see `tests/unit/test_chunked_analyzer.py:50`). Fix: validate `provider_name` at the TOP of `analyze_chunked` — BEFORE split_video runs, BEFORE cost_tracker.estimate is called — with a clear `ValueError` that names the disallowed value AND the allowed set.

**CLEAN-07 (MR-03):** In `on_chunk_error="continue"` mode, `analyze_chunked` at lines 442-454 drops failed chunks from `pairs` and forwards only the survivors to `merge_analyses`. The merger's `_merge_narrative` then picks `hook_*` from `dims[0]` and `cta_*` from `dims[-1]` — which are the SURVIVORS' first and last, NOT the original video's first and last. If chunk 0 failed, the merged `hook_type` silently comes from what was originally chunk 1 — a position lie. If only chunk 1 survives from a 3-chunk video, the merger takes the N=1 pass-through path and emits that middle chunk's local hook/cta as if they were the video-wide hook/cta.

**Fix per CONTEXT.md (locked approach #1 from CONTEXT.md `## Implementation Decisions`):** pass the full `(chunk, art_or_None)` list to the merger so it can pick:
- `hook_*` = lowest-index chunk where `art is not None` (by original submission order, i.e. by `chunk.start_global`)
- `cta_*` = highest-index chunk where `art is not None` (same order)
- All other per-dimension merges (weighted averages, majorities, concat) operate only on the survivors (unchanged math; only the position-dependent hook/CTA picks change).
- If NO chunk survived, the existing "All chunks failed" RuntimeError still fires upstream in `analyze_chunked` — the merger's new code path handles survivors count ≥ 1.

Purpose: invalid providers fail fast with a clear argument-error (saves a full split → analyze → merge cycle). continue-mode merged artifacts stop lying about video-wide hook/CTA when edge chunks die.

Output: `_ALLOWED_PROVIDERS` constant + top-of-function validation in `chunked_analyzer.py`; updated merger signature or internal dispatch that respects original positions; targeted tests for both behaviors.
